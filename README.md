# k-clustering-minimum-biclique-completion-problem

The three sets of 63 benchmark instances, including 9 small-scale instances in Set I, 18 medium- and large-scale instances in Set II, and 36 more challenging large-scale instances in Set III, 
used in our paper titled with "A pattern mining-based hybrid evolutionary algorithm for k-clustering minimum biclique completion problem" are taken from the corresponding literature (refer to []). To facilitate the further research, we upload the instances here.

The software and data in this repository are a snapshot of the software and data that were used in the research reported in the paper “A frequent pattern mining-based hybrid evolutionary
algorithm for the k-clustering minimum biclique completion problem” by Dawei Wu, , Zhiying Zhnag, and Qing Zhou.
