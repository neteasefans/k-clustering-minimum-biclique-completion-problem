# k-clustering-minimum-biclique-completion-problem

The software and data in this repository are a snapshot of the software and data that were used in the research reported in the paper “A frequent pattern mining-based hybrid evolutionary
algorithm for the k-clustering minimum biclique completion problem” by Dawei Wu, , Zhiying Zhang, and Qing Zhou.

## How to run the programs.

** Instructions to use the source code of FPMHEA

*** To compile:

q.zhou$ make

q.zhou$

*** To run:

q.zhou$ ./main_exe ./input_file seed ./output_file

(where input_file is the instance name, seed is the given random seed, such as 1, 2, ... times, and output_file records the output information)

## Materials
This repository includes the following materials:

--Benchmark instances used in our paper (see the directory named instances).

--Source codes of the proposed FPMHEA (see the directory named src for the details.)   

--makefile which is used to compile the source code
